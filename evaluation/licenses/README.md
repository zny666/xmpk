# Upstream terms and attribution

The repository's Xmpk license does not replace third-party terms.

| Material | Preserved terms and location |
|---|---|
| MAYO reference and modified arithmetic | Apache-2.0, upstream `mayo/LICENSE` and `mayo/NOTICE` |
| UOV reference and modified matrix code | Upstream public-domain/CC0 or Apache-2.0 option in `uov/LICENSE` |
| MQOM reference and modified PIOP code | MIT, CryptoExperts notices in each parameter's `LICENSE` |
| SNOVA reference and adaptations | MIT, SNOVA TEAM notices in each parameter's `LICENSE` |
| QR-UOV reference and adaptations | Official Round-3 IP statement, section 2.D.3, in `qruov-IP-statements.pdf` |
| CVA6 and its RTL dependencies | Original SPDX/header notices and texts under `../ppa/licenses/cva6` |
| Spike-derived bare-metal environment | Original headers and `../api/integrated-20261112/build-support/verif/tests/custom/env/LICENSE` |

The algorithm licenses are retained alongside each API and profiling source
tree. Modified files retain their existing headers. The integration patch and
the `CHANGES.json`/before versions identify project modifications.

QR-UOV's official statement grants the U.S. Government and any interested
party the stated rights to reproduce, derive, distribute and display
implementations for NIST public evaluation and standardized implementation.
Consult the original statement for its exact terms and scope. The source
archive SHA-256 is
`268a3990d37b84d64e423587157bfdb45a966302f39bbfae7f6095436bfc3423`.

The export verifier checks that preserved license/notice files have identical
original and exported SHA-256 hashes. Research data and newly authored export
tools use the repository's license; imported third-party software keeps the
terms above.

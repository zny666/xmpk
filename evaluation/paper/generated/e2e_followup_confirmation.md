API 累计因子按逐轮乘积 Γ=Πγ 计算，始终从
e2e_before_refinements.csv 原始周期换算：C_new=round(C_original/Γ)。
整轮为三个更新后的 API 周期之和，不再次除以报告的整轮因子。
整轮观测值保存在 history 的 whole-report 行，仅作校验；
五项差异均在三位小数的舍入范围内。
重复运行更新脚本不会重复应用本轮因子。

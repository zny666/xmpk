# Fixed-Assumption End-to-End Cycle Projection

Generated by `tools/estimate_e2e_cycles.py`. These are projected architectural cycles, not completed RTL measurements.

## Fixed assumptions

- Reference clock: 2.2 GHz.
- CVA6 effective IPC: 0.400.
- Baseline formula: `R20_ms * 2.2e6 * profile_IPC / 0.4`.
- Projection formula: `C_xmpk = C_base * (1 - sum(f_i) + sum(f_i / S_i))`.

## Allocation basis

- MQOM and UOV fractions come directly from sampled Algebra or named matrix/solve symbols.
- QR-UOV L3 assigns 60--66.7% to EXTGEMM, preserving the observed roughly one-third PRG/expansion residual in signing.
- MAYO allocates fixed shares of opaque inlined parent functions to QGEMM/SOLVEQ while leaving all sampled AES unaccelerated.
- SNOVA allocates 50--55% to QGEMM/LINXFM; the 16x LINXFM proxy keeps the projected 2.13x signing result close to the independent 2.09x RVV end-to-end observation.
- `SOLVEQ-GF16-proxy=33.61x` is a fixed projection proxy, not a measured GF16 N=64 scalar comparison.
